# Apache Camel reference

This directory contains the Apache Camel reference for Gregor. The content applies to Apache Camel 4.21.0.
It contains only the parts that apply to this project.

Use these files during route work:

- [Java DSL](java-dsl.md)
- [Camel 4.21 upgrade guide](camel-4.21-upgrade-guide.md)
- [Choice EIP](choice-eip.md)
- [Bean EIP](bean-eip.md)
- [Direct component](direct-component.md)
- [Kafka component](kafka-component.md)

These files summarize the Apache Camel documentation. They do not copy the complete component option catalog.
Use the upstream source links in each file only to update this local reference.

Update this directory when the Camel version in `build.gradle` changes. Review all intermediate Camel upgrade guides.
